# 월계관 닉네임 송출 오버레이

OBS Browser Source와 일반 브라우저에서 사용할 수 있는 투명 Canvas 기반 수상자 오버레이입니다. 최대 3명의 기본 수상자와 5명의 추가 수상자를 한 화면에 표시할 수 있습니다.

## 주요 기능

- 월계관 디자인 17종 (기존 16종 + 미니멀 리프 SVG)
- 기본 금·은·동·민트 4색, 확장 8색 및 수상자별 직접 색상 지정
- 순위, 닉네임, 하단 문구와 폰트 설정
- 크기, 간격, 속도와 애니메이션 효과 조절
- 실제 내용 영역에 맞춘 투명 PNG 저장
- 투명 배경 애니메이션 GIF 저장
- 외부 CDN 없이 동작하는 정적 HTML/CSS/JavaScript 구성

## 사용 방법

1. `index.html`을 브라우저에서 열거나 배포된 사이트에 접속합니다.
2. 수상자와 월계관, 색상, 크기 및 효과를 설정합니다.
3. PNG 또는 GIF로 저장해 방송 화면에 사용합니다.

기본 화면을 OBS Browser Source로 띄우려면 사이트 주소에 `?overlay=1`을 붙입니다. 편집한 설정은 이 주소에 자동으로 반영되지 않습니다.

## 이미지 저장

- `PNG 저장`: 미리보기 크기를 기준으로 투명 여백을 제거해 내용에 딱 맞게 저장합니다.
- `GIF 저장`: 전체 프레임의 내용 영역만 남겨 반복 애니메이션으로 저장합니다. 크기 설정은 최대 너비이며, 작은 이미지를 확대하지 않습니다.

GIF는 포맷 특성상 256색과 1비트 투명도만 지원합니다. 깨끗한 투명 배경을 위해 일부 반투명 파티클 효과는 GIF 저장 시 자동으로 제외됩니다.

## 프로젝트 구성

- `index.html`: 화면 구조와 설정 패널
- `styles.css`: 화면 및 오버레이 스타일
- `app.js`: Canvas 렌더링, URL 설정, PNG/GIF 저장
- `assets/laurelExtraPaths.js`: 월계관 벡터 데이터
- `assets/fonts/*.woff2`: 웹용 압축 폰트
- `vendor/gif.js/`: 로컬 GIF 인코더와 Worker
