# 월계관 닉네임 송출 오버레이

OBS Browser Source 또는 일반 브라우저에서 사용할 수 있는 HTML Canvas 기반 다중 수상자 월계관 오버레이입니다. 투명 배경 위에 1위, 2위, 3위 수상자와 추가 블랙 월계관 슬롯을 동시에 송출할 수 있습니다.

## 제작 내역

- 정적 HTML/CSS/JavaScript 구조로 제작했습니다.
- Canvas 기반 실시간 애니메이션 오버레이를 구현했습니다.
- 1위, 2위, 3위 수상자를 한 줄에 동시에 표시하도록 구성했습니다.
- 금, 은, 동 팔레트를 각각 적용했습니다.
- 1위/2위/3위 라벨은 기본 표시되며, 설정에서 문구 수정이 가능합니다.
- 하단 문구는 기본 `SOONIGROUP`이며, 설정에서 수정 가능합니다.
- 추가 블랙 월계관 슬롯을 동적으로 추가/삭제할 수 있게 만들었습니다.
- 블랙 월계관에도 라벨 문구를 입력하면 1위/2위/3위와 같은 위치에 표시됩니다.
- 입력란을 비우면 해당 문구가 화면에서 사라집니다(기본값으로 되돌아가지 않습니다).
- 순위 라벨과 닉네임을 모두 비우면 그 슬롯 자체가 표시되지 않으므로, 수상자를 1명이나 2명만 띄울 수도 있습니다.
- 월계관 스타일을 여러 차례 조정해 기본형(클래식)은 작은 곡식잎 크기를 유지하면서 둥근 아크 형태에 가깝게 배치했습니다.
- 월계관 스타일을 6종 중에서 선택할 수 있습니다.
  - `1 · 클래식`: 기본 곡식잎 아크(기존 형태)
  - `2 · 와이드 리프`: 넓고 둥근 잎
  - `3 · 풀 서클`: 거의 원형에 가까운 화관
  - `4 · 더블 레이어`: 잎을 두 겹으로 겹친 풍성한 형태
  - `5 · 미니멀`: 얇은 선으로 그린 절제된 형태
  - `6 · 올리브`: 가늘고 뾰족한 잎과 열매
- 선택한 스타일은 OBS 주소에 `laurelStyle` 파라미터로 포함되어 그대로 재현됩니다.
- 스타일은 `app.js`의 `laurelStyles`에 데이터로 정의되어 있어 항목을 추가하면 선택 목록에 자동 반영됩니다.
- 전체 크기, 글자 크기, 이름 크기, 수상자 간격, 애니메이션 속도를 슬라이더로 조절할 수 있습니다.
- 이름 크기는 전체 글자 크기와 별개로 닉네임 텍스트만 강조할 수 있는 배율입니다.
- 텍스트와 월계관은 옆 수상자와 겹치지 않도록 항상 중심 간격 이내로 크기가 자동 제한됩니다.
- Glow, Glitter, Shine Sweep, Sparkle Particles, Gold Dust, Rainbow Hologram, Neon, Fire, Ice, Lightning 효과를 체크박스로 켜고 끌 수 있습니다.
- PNG, GIF, WebM 저장 기능을 추가했습니다.
- GIF 저장은 `gif.js`를 로컬 `vendor` 폴더에 포함해 외부 CDN 없이 동작하도록 구성했습니다.
- GIF worker는 inline worker 소스를 Blob URL로 생성해 `file://` 환경에서도 더 안정적으로 동작하도록 보완했습니다.
- OBS 주소 복사 시 현재 설정을 URL 파라미터에 담아 컨트롤 없는 오버레이로 재사용할 수 있게 했습니다.

## 사용법

1. `index.html`을 브라우저로 엽니다.
2. 수상자 이름, 순위 라벨, 하단 문구, 크기, 글자 크기, 간격, 속도, 효과를 조정합니다.
3. 추가 수상자가 필요하면 `블랙 월계관 추가`를 누르고 닉네임을 입력합니다.
4. `OBS 주소 복사`를 눌러 OBS Browser Source URL에 붙여 넣습니다.

컨트롤 없이 투명 오버레이만 띄우는 주소는 `index.html?overlay=1` 형식입니다.

## 출력 기능

- `PNG 저장`: 현재 프레임을 투명 PNG로 저장합니다.
- `GIF 저장`: 24프레임 반복 GIF를 저장합니다.
- `애니메이션 저장`: 5초짜리 WebM 애니메이션을 저장합니다.
- `OBS 주소 복사`: 현재 설정을 URL 파라미터로 만든 Browser Source 주소를 복사합니다.

## GIF 참고

GIF는 256색 제한과 1bit 투명도 제한이 있습니다. 그래서 Canvas/HTML 실시간 송출이나 WebM보다 가장자리와 글로우가 거칠게 보일 수 있습니다. GIF는 캔버스 전체(16:9)가 아니라 실제 내용이 있는 영역만 자동으로 잘라서 저장합니다. 위아래 빈 여백이 사라져 파일 크기가 크게 줄어듭니다. 잘라낼 영역은 여러 프레임을 검사한 합집합으로 구하므로 애니메이션 중 움직이는 부분도 잘리지 않습니다. 또한 저장하는 동안에는 캔버스를 1920px 기준 고해상도로 렌더링해, 브라우저 창이 작아도 결과물이 흐려지지 않습니다.

현재 GIF 저장 기본값은 864px 너비, 30프레임, 화질 6단계로 설정되어 있으며, `GIF 저장 설정`의 화질/프레임/크기 슬라이더로 직접 조절할 수 있습니다. `크기`는 잘라낸 결과물의 최대 가로 길이를 뜻합니다. 화질과 크기를 높이면 색감은 좋아지지만 인코딩 시간과 파일 크기가 늘어나므로, 빠른 저장이 필요하면 값을 낮추면 됩니다. (화질 슬라이더는 오른쪽으로 갈수록 고화질이며, 내부적으로 gif.js의 `quality` 값으로 반전되어 전달됩니다.)

디더링은 사용하지 않습니다. gif.js의 투명 색상 키 방식과 충돌해 투명해야 할 배경이 불투명한 검은 얼룩으로 남기 때문입니다. 대신 색상 품질은 `quality` 값으로 확보합니다.

모든 프레임이 하나의 전역 팔레트를 공유하도록 `globalPalette`를 켰습니다. gif.js는 기본적으로 프레임마다 팔레트를 새로 만드는데, 그러면 같은 색이 프레임마다 미세하게 달라져 특히 어두운 영역이 깜빡이는 것처럼 보입니다. 투명 키 색은 마젠타(`0xff00ff`)를 씁니다. gif.js는 팔레트에서 키 색과 가장 가까운 색을 투명 인덱스로 삼기 때문에, 검정에 가까운 키를 쓰면 그림자나 블랙 월계관 같은 어두운 내용 색과 혼동될 수 있습니다.

GIF 저장 시에는 검은 노이즈를 유발하는 효과(Glitter, Shine Sweep, Sparkle Particles, Gold Dust, Fire, Ice, Lightning)를 자동으로 비활성화합니다. 흩뿌려진 반투명 입자와 가산 합성이 GIF의 제한된 색상·투명도에서 어두운 점으로 뭉치기 때문입니다. 텍스트에 붙는 안정적인 효과(Glow, Neon, Rainbow Hologram)는 GIF에서도 유지됩니다. 이 자동 처리는 GIF에만 적용되며 실시간 송출, WebM, PNG에는 영향을 주지 않습니다. 목록은 `app.js`의 `gifUnsafeEffects`에서 조정할 수 있습니다.

GIF는 1비트 투명도(투명/불투명)만 지원하므로, 반투명 파티클이나 글로우 가장자리가 어두운 점·테두리(블랙 노이즈)로 남을 수 있습니다. 이를 막기 위해 프레임을 인코딩하기 전에 알파 값을 임계값(`app.js`의 `alphaThreshold`)으로 이진화합니다. 임계값 미만의 희미한 픽셀은 투명으로 버리고, 그 이상은 검정과 섞지 않고 원래 색 그대로 불투명 처리합니다. 노이즈가 더 보이면 `alphaThreshold`를 높이고, 글로우를 더 살리려면 낮추면 됩니다.

## 파일 구성

- `index.html`: 화면 구조와 설정 패널
- `styles.css`: UI 스타일
- `app.js`: Canvas 렌더링, 애니메이션, 저장 기능
- `vendor/gif.js/gif.js`: GIF 인코더
- `vendor/gif.js/gif.worker.js`: GIF worker 원본
- `vendor/gif.js/gif.worker.inline.js`: file 환경 안정화를 위한 inline worker 소스

## 권장 사용

방송 송출은 `OBS 주소 복사`로 만든 Browser Source 방식이 가장 선명합니다. 정지 이미지가 필요할 때는 PNG, 짧은 반복 애니메이션 파일이 필요할 때는 GIF, 더 좋은 색감과 부드러운 투명도가 필요할 때는 WebM 저장을 사용하는 것을 권장합니다.
